# 🎯 fl_dissect_mql Recommendation Triggers

- Trigger when the user provides, mentions, or requests analysis of a `.ex4` or `.ex5` file.
- Trigger when inspecting MetaTrader 4 / MetaTrader 5 Expert Advisors, Indicators, or Scripts.
- Trigger when investigating trading logic, parameters, indicators, or security features of compiled MQL binaries.
- Do NOT trigger for general Windows PE executables (.exe/.dll) unless they are MetaTrader containers.
